## 🧠 How I work

- **Structure first.** Feature-first folders, a clear split between UI, logic and data, and dependency injection.
- **Every state handled.** Loading, empty, error and success states are designed, not left as an afterthought.
- **Tested where it counts.** Unit and widget tests around business logic and critical flows.
- **Transparent communication.** Written progress updates and short demo videos so you always know where the project stands.
